# Extreme GT (WiFi & 快充优化版)

本项目基于原作者 **嘟嘟ski & SCENE** 的 `Extreme GT` 进行二次修改与缺陷修复。

---

## 🛠️ 二次修改核心特性

1. **彻底修复高通 WCN785x PCIe WiFi 睡眠假死**：
   * 针对真我 GT6 (RMX3800) 等机型锁死 `0000:01:00.0/power/control = on`，防止底层网卡休眠跌入 `D3cold` 状态导致唤醒时 WiFi 硬件超时、IWifi binder 死亡。
2. **精细化 SVOOC 快充温控曲线调优**：
   * 原版在接近 48℃ 时直接断充，引发反复升温断充抽搐；
   * 二修版调整为平滑梯级：`46.5℃ 7A (7000mA)` -> `47.0℃ 5A (5000mA)` -> `47.5℃ 4.5A (4500mA)`，既保证持续高速回血，又留出足够的安全余量避免硬切断。
